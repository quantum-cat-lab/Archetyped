# Archetyped: Введение и Ядро

Archetyped — это высокопроизводительный модульный движок, построенный на минималистичном ядре и архитектуре команд "Fast Utility Router" (FUR).

## Обзор архитектуры

Движок состоит из двух основных частей:
1.  **FractalKernel**: Центральный узел, который маршрутизирует команды между различными модулями и сервисами.
2.  **Сервисы**: Независимые модули (ECS, SQLDB, EventBus и т. д.), которые регистрируют свои методы в ядре.

Связь между SDK (или другими модулями) и сервисами осуществляется через **FUR Команды**.

## Система команд FUR

Каждая операция в движке инкапсулирована в `FURCMDPacket`.

### Структура FURCMDPacket

```cpp
struct FURCMDPacket {
    uint32_t methodHash;    // FNV1a хэш имени метода (например, "archetyped:ecs:registerComponent")
    uint16_t payloadSize;   // Размер отправляемых данных
    uint16_t flags;         // Системные флаги
    void* payload;          // Указатель на входные данные (структура контекста)
    void* outputBuffer;     // Указатель на буфер для возвращаемых значений
    uint64_t* fence;        // Указатель на атомарный флаг синхронизации (Ticket)
};
```

### Синхронизация (Билеты/Tickets)

Поскольку ядро обрабатывает команды асинхронно, движок использует **Билеты (Tickets)** для отслеживания завершения задач.

-   **Ticket**: Содержит атомарный `fence`. Когда движок завершает задачу, он устанавливает `fence` в значение 1.
-   **TicketPool**: Предварительно выделенный пул билетов для предотвращения выделения памяти во время выполнения.

**Пример: Ожидание завершения команды**
```cpp
Ticket* ticket = FractalSDK::SDK::Get()->allocateTicket();
packet.fence = (uint64_t*)&ticket->fence;

SDK::Get()->sendPacket(packet);

while(!ticket->isReady()) {
    // Ждем или выполняем другую работу
}
```

## Инициализация

Перед использованием любых сервисов движка необходимо инициализировать `FractalSDK`.

```cpp
#include "Engine/FractalSDK.h"

// Предполагается, что 'kernel' предоставлен хостом движка
FractalSDK::SDK::Initialize(kernel);

// ... использование сервисов движка ...

FractalSDK::SDK::Shutdown();
```

## Основные принципы

-   **Типобезопасность**: Хотя пакеты FUR используют `void*`, высокоуровневые обертки (ECS, SQLDB) предоставляют типобезопасные шаблоны.
-   **Асинхронность**: Большинство команд можно отправлять, не блокируя основной поток.
-   **Слабая связанность**: Сервисы не знают друг о друге; они взаимодействуют только через Ядро.
